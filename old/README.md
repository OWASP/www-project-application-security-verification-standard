# Archived website files

These files were retired after the Just the Docs rework and are kept for historical reference. Jekyll excludes this entire directory from publication.

- Root Markdown files: old OWASP tabs, sidebar content, and wiki migration placeholder. Current content lives in `index.md` and `mainsite/`.
- `_layouts/`: the old OWASP sidebar layout.
- `assets/images/`: unused supporter images and the former image-folder placeholder README. The Apiiro logo previously appeared only in a commented-out supporter entry.

Archived files retain their original contents and relative directory structure; their old links are not maintained.
